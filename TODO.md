
## Визуальное распознавание панелей
- [x] В одну кнопку «Сканировать камерой» объединены распознавание QR/штрихкода через `html5-qrcode` и распознавание лицевой поверхности панели по эталонным изображениям из `CatalogNew (11).html`.
- [x] При визуальном совпадении показываются тип/серия и артикул; существующая складская позиция открывается в карточке, а неизвестная позиция подставляется в форму добавления каталога.
- [x] Визуальная база встроена в автономный `index.html`, чтобы функция сохранялась при запуске файла из одной папки.
