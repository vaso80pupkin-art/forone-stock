# FORONE Stock — журнал улучшений

## Улучшение камеры и распознавания
- [x] Автонастройка continuous focus/exposure и поддерживаемой яркости после запуска камеры.
- [x] Масштаб камеры с кнопками +/- и отображением текущего значения.
- [x] Усиление контраста, яркости и резкости кадра перед визуальным сопоставлением.
- [x] Отображение процента уверенности и предупреждение при низкой уверенности.
- [x] Показ и выбор нескольких похожих панелей.

## Режимы сканера
- [x] Добавлены режимы «Проверить наличие», «Приход», «Расход» и «Списание на замер».
- [x] В режиме проверки остаток не изменяется.
- [x] Для расхода и списания проверяется доступный остаток с учётом резерва.
- [x] Карточка товара открывается с выбранным режимом и правильной кнопкой действия.

## Excel
- [x] Перед импортом показывается выбранный лист, таблица строк и сводка найденных позиций.
- [x] В предпросмотре видны обновляемые позиции, дубликаты и строки с пустыми артикулами.
- [x] Импорт подтверждается отдельной кнопкой после предпросмотра.

## Складские данные
- [x] Добавлены склад, зона, стеллаж и ячейка.
- [x] Отдельно отображаются фактический остаток, резерв и доступно к продаже.
- [x] Добавлены быстрые фильтры: нет в наличии, мало, панели 4 м, луверы и недавно изменённые.
- [x] Место хранения и резерв включаются в экспорт отчёта.

## Резервная копия
- [x] Сохранение полной базы в JSON.
- [x] Восстановление базы с проверкой файла и подтверждением замены.
- [x] Передача базы через системное меню телефона или скачивание файла для отправки вручную.
- [x] Обновлена версия Service Worker.

## Google Sheets
- [x] Добавлена прямая загрузка публичной Google-таблицы по ссылке через XLSX export.
- [x] Добавлен выбор листа перед первым обновлением; выбранный лист запоминается.
- [x] После первого подтверждения включённые автоматические обновления применяются без повторного диалога.
- [x] Добавлена ручная кнопка «Обновить сейчас» и статус последней синхронизации.
- [x] При анализе исключаются листы заказов, статистики, аналитики, отгрузок, брака, цен и истории; основной кандидат — лист с колонками «Артикул» и «Остаток на складе».

## Мобильная адаптация
- [x] Режимы сканера переведены в адаптивную сетку 2×2.
- [x] Кнопка запуска камеры вынесена в отдельную строку без наложения.
- [x] Исправлена ширина панели статуса подключения на узких экранах.
- [x] Исправлена раскладка панели каталога и карточек товара на ширине до 480 px.
